# Территория Спорта КИДС — лендинг

Одностраничный сайт детского центра гимнастики, воссозданный по макету (Figma/PDF).
Чистый HTML / CSS / JavaScript — без сборки, открывается напрямую или с любого статического хостинга
(GitHub Pages, Netlify, Vercel).

## Запуск

Просто откройте `index.html` в браузере, либо поднимите статический сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
index.html        — разметка всех секций
styles.css        — стили, цвета, адаптив (брендовые цвета вынесены в :root)
script.js         — анимации появления, карусели, аккордеоны, отправка в WhatsApp
assets/img/       — логотип, маскот, фото зала, тренеры (извлечены из макета)
```

## Что реализовано

- **Анимация при скролле** — секции и изображения плавно появляются снизу вверх
  (IntersectionObserver, класс `.reveal`).
- **Карусели со стрелками** — для программ («Чем будем заниматься?») и тренеров
  («Наши тренеры»): рабочие стрелки ◀ ▶, точки-индикаторы, свайп на тач-устройствах.
  Карусель отзывов — тоже со стрелками.
- **Аккордеоны** — «Что есть у нас в зале?» и FAQ.
- **WhatsApp** — все кнопки записи и формы (запись на пробное занятие, форма отзыва,
  плавающая кнопка) открывают чат WhatsApp с заранее заполненным сообщением.

## Как поменять номер WhatsApp

Номер задан в одном месте — `script.js`:

```js
var WHATSAPP_NUMBER = '77054290000'; // +7 705 429 0000  (только цифры, с кодом страны)
```

Также телефон/ссылки `tel:` и плавающая кнопка в `index.html`
(поиск по `77054290000` и `8 705 429 0000`).

## Замена изображений

Файлы лежат в `assets/img/`. Чтобы заменить — положите файл с тем же именем
(тренеры: `coach-1/2/3.png`, фото зала: `gym-*.jpg`, маскот: `mascot-*.png`).
