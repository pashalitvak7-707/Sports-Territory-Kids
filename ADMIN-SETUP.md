# Админ-панель — подключение и использование

Сайт остаётся статическим (GitHub Pages / Netlify / Vercel), а контент и заявки
хранятся в бесплатном облачном сервисе **Supabase**. Пока Supabase не подключён,
сайт работает как раньше — со стандартным контентом из HTML.

## Подключение (один раз, ~10 минут)

### 1. Создать проект Supabase

1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** → войдите через Google.
2. Создайте проект: имя любое (например `sports-territory-kids`), пароль базы — сгенерировать и сохранить, регион — **Europe (Frankfurt)**.
3. Подождите ~2 минуты, пока проект создаётся.

### 2. Вписать ключи в сайт

Project Settings (шестерёнка) → **API**: скопируйте **Project URL** и **anon / publishable key**.
Впишите их в файл `cms-config.js`:

```js
window.CMS_CONFIG = {
  url: 'https://ваш-проект.supabase.co',
  anonKey: 'ваш anon ключ'
};
```

Эти два значения публичные — их можно хранить в коде сайта.
**Никогда** не вставляйте в код ключ с пометкой `service_role` / `secret`.

### 3. Создать базу данных

Dashboard → **SQL Editor** → New query → вставьте целиком содержимое файла
`supabase-setup.sql` → **Run**. Скрипт создаёт таблицы, права доступа,
хранилище картинок и заполняет расписание и тренеров текущими данными сайта.

> В скрипте задан email администратора (см. функцию `is_admin` в
> `supabase-setup.sql`). Только пользователь с этим email может менять контент.
> Чтобы сменить email — поправьте его в скрипте и запустите скрипт заново.

### 4. Создать логин администратора

Dashboard → **Authentication** → **Users** → **Add user** → **Create new user**:
email — тот же, что в шаге 3, пароль — придумайте надёжный.
Поставьте галочку **Auto Confirm User**, если она есть.

### 5. Запретить самостоятельную регистрацию

Dashboard → **Authentication** → **Sign In / Providers** (или Settings) →
выключите **Allow new users to sign up**. Тогда войти в админку сможете только вы.

## Использование

Админ-панель: откройте **`admin.html`** на вашем сайте
(например `https://ваш-сайт/admin.html`) и войдите со своим email и паролем.

Вкладки:

- **Заявки** — все заявки с форм сайта (запись на занятие и пробное).
  Посетителю по-прежнему открывается WhatsApp, а копия сохраняется здесь.
- **Отзывы** — новые отзывы приходят «на проверку»; на сайте появляются
  только после нажатия «Опубликовать» (показываются последние 4).
- **Расписание** — добавление, изменение и удаление занятий: направление,
  возраст, день, время, тренер, свободные места. Сортировка по дню и времени
  происходит автоматически. 0 мест = «Нет мест» на сайте.
- **Тренеры** — карточки раздела «Наши тренеры»: имя, должность, опыт,
  описание, фото (загружается в облако), порядок стрелками ↑↓.
- **Тексты** — заголовки и тексты основных разделов. Пустое поле = стандартный
  текст. Перенос строки в поле = перенос строки на сайте.
- **Оформление** — фирменные цвета, шрифт, логотип и главное фото.
- **Контакты** — телефон и номер WhatsApp для всех кнопок сайта.

Изменения появляются на сайте сразу после обновления страницы у посетителя.

## Как это устроено (для разработчика)

- `cms-config.js` — адрес и публичный ключ Supabase.
- `cms.js` — на публичных страницах подгружает контент из Supabase (REST)
  и подставляет его в HTML; при ошибке/отсутствии настройки ничего не меняет.
- `admin.html` / `admin.css` / `admin.js` — сама панель (supabase-js с CDN,
  вход по email/паролю через Supabase Auth).
- `supabase-setup.sql` — схема, row-level-security политики, стартовые данные.
- Безопасность: писать в базу может только вошедший пользователь с email из
  `is_admin()`; посетители могут только читать контент и отправлять
  заявки/отзывы (отзывы всегда со статусом «не опубликован»).
